# 手搓一把公式计算计算过程 👋
线性代数相关概念解释：
1）点积是什么？给两个向量：a=[a1,a2,...,ad],b=[b1,b2,...,bd]，点积就是：a⋅b=a1b1+a2b2+⋯+adbd，它是一个数字，不是向量。点积是 “两个向量之间的关系计算”。
2）线性变换是什么？线性变换 = 矩阵乘法 Wx,它把一个向量从一个空间映射到另一个空间。例如：Xnew=Wx,常见的有旋转、拉伸、压缩、升维都叫线性变换。线性变换是 “对一个向量做空间变形，线性变换遵循：1.原点不变  2. 始终是条直线。
3）线性可分视角：神经网络的学习就是学习如何利用矩阵的线性变换加激活函数的非线性变换，将原始输入空间投向线性可分/稀疏的空间去分类/回归。

# Attention 机制详解

## 一、Attention 机制核心原理

### 1.1 一句话总结

> **Attention = 在高维空间中计算查询与键的匹配程度，用匹配结果加权值。**

Query 代表"我想知道什么"，Key 代表"我有什么信息可以匹配"，Value 代表"实际要传递的内容"。

### 1.2 缩放点积注意力（Scaled Dot-Product Attention）

**公式：**

```
Attention(Q, K, V) = softmax(QK^T / √d_k) V
```

**计算步骤：**

```
Step 1: 计算 Q·K^T（点积/匹配度）
Step 2: 除以 √d_k（缩放，防止梯度消失）
Step 3: Softmax（归一化为概率分布）
Step 4: 加权求和 @ V
```

**PyTorch 实现：**

```python
def scaled_dot_product_attention(Q, K, V):
    """
    实现缩放点积注意力
    参数:
        Q: 查询向量, shape=(d_k,)
        K: 键矩阵, shape=(n, d_k)
        V: 值矩阵, shape=(n, d_v)
    返回:
        output: 注意力输出, shape=(d_v,)
        attention_weights: 注意力权重, shape=(n,)
    """
    # 步骤1: 计算 Q 与 K 的点积（匹配度）
    d_k = K.shape[-1]
    dot_product = np.dot(Q, K.T)  # shape=(n,)
    
    # 步骤2: 缩放，除以 √d_k 防止梯度消失
    scaled_dot = dot_product / np.sqrt(d_k)
    
    # 步骤3: Softmax 归一化为注意力权重
    exp_scaled = np.exp(scaled_dot - np.max(scaled_dot))  # 防止溢出
    attention_weights = exp_scaled / np.sum(exp_scaled)
    
    # 步骤4: 加权求和 V 得到输出
    output = np.dot(attention_weights, V)
    return output, attention_weights
```

### 1.3 手动计算示例

假设 4 维向量，3 个词：

```
Q（查询-桃花）= [0.9, 0.8, 0.1, 0.2]
K（键）:
  桃花 K1 = V1 = [0.9, 0.8, 0.1, 0.2]
  梨花 K2 = V2 = [0.8, 0.9, 0.2, 0.1]
  苹果 K3 = V3 = [0.1, 0.2, 0.9, 0.8]

Step 1: Q·K^T = [1.50, 1.48, 0.50]
Step 2: 缩放 / √4 = [0.75, 0.74, 0.25]
Step 3: Softmax = [0.385, 0.381, 0.234]
        （桃花 38.5%, 梨花 38.1%, 苹果 23.4%）
Step 4: 输出 = 0.385×V1 + 0.381×V2 + 0.234×V3
       = [0.728, 0.728, 0.272, 0.272]
```

**物理意义：** "桃花"这个词的注意力输出，融合了桃花自身、梨花（近亲）和苹果（远亲）的信息，权重由各者的匹配度决定。

## 二、Q/K/V 的线性变换

Q、K、V 不是原始输入，而是通过可学习的线性变换得到的：

```
Q = x · W_Q
K = x · W_K
V = x · W_V
```

其中 `W_Q`, `W_K`, `W_V` 是可训练的权重矩阵。

**为什么要变换？**

- 原始输入 x 在固定空间中，不同语义关系的匹配可能不够灵活
- 通过 W_Q, W_K, W_V 三个不同的线性变换，将输入映射到三个不同的子空间
- 在每个子空间中，Q 和 K 的点积才有意义
- 这相当于为模型提供了"多角度观察"的能力

---

## 三、多头注意力（Multi-Head Attention）

### 3.1 为什么需要多头？

单头注意力的问题：
- 只有一个注意力分布，只能关注一种关系
- 比如：桃花 vs 桃花（自关联）、桃花 vs 梨花（近亲）、桃花 vs 苹果（远亲）
- 这些不同类型的关系应该有不同的权重

**多头注意力 = 多个独立的注意力头并行工作，每个头关注不同的语义子空间。**

### 3.2 计算流程

```
输入 x: shape = [batch_size, seq_len, d_model]
d_model = 512, h = 8 个头

Step 1: 线性变换 → 得到 Q, K, V
  Q = x · W_Q    shape: [batch, seq_len, d_model]
  K = x · W_K    shape: [batch, seq_len, d_model]
  V = x · W_V    shape: [batch, seq_len, d_model]

Step 2: 分割为多头
  Q_head_i = Q · W_Q^i   shape: [batch, seq_len, d_k], d_k = d_model/h = 64
  K_head_i = K · W_K^i   shape: [batch, seq_len, d_k]
  V_head_i = V · W_V^i   shape: [batch, seq_len, d_v]

Step 3: 每个头独立计算注意力
  head_i = Attention(Q_head_i, K_head_i, V_head_i)

Step 4: 拼接所有头的输出
  concat_heads = [head_1, head_2, ..., head_h]
  shape: [batch, seq_len, d_model]

Step 5: 最终线性变换
  output = concat_heads · W_O
```

### 3.3 PyTorch 实现

```python
class MultiHeadedAttention(nn.Module):
    def __init__(self, h, d_model, dropout=0.1):
        super().__init__()
        assert d_model % h == 0  # 确保能整除
        self.d_k = d_model // h  # 每头维度
        self.h = h               # 头数
        
        # 3个线性层用于 Q/K/V，1个用于输出拼接
        self.linears = clones(nn.Linear(d_model, d_model), 4)
        
    def forward(self, query, key, value, mask=None):
        if mask is not None:
            mask = mask.unsqueeze(1)  # 适配多头
        
        nbatches = query.size(0)
        
        # Step 1-2: 线性变换 + 分割为多头
        # [batch, seq_len, 512] → [batch, 8, seq_len, 64]
        query, key, value = [
            lin(x).view(nbatches, -1, self.h, self.d_k).transpose(1, 2)
            for lin, x in zip(self.linears, (query, key, value))
        ]
        
        # Step 3: 多头注意力（PyTorch 广播自动并行）
        x, self.attn = attention(
            query, key, value, mask=mask, dropout=self.dropout
        )
        
        # Step 4-5: 拼接 + 线性变换
        # [batch, 8, seq_len, 64] → [batch, seq_len, 512]
        x = x.transpose(1, 2).contiguous().view(nbatches, -1, self.h * self.d_k)
        
        return self.linears[-1](x)
```

### 3.4 各头关注的语义

不同注意力头会自动学习到不同的关注模式：

- **头1**：语法关系（主谓宾）
- **头2**：语义关联（近义词）
- **头3**：指代消解（"它"→"桃花"）
- **头4**：远距离依赖（首尾呼应）

## 四、掩码机制（Masking）

### 4.1 Padding Mask（填充掩码）

**用途：** 处理变长序列的 Padding

**问题：** 同一 Batch 中句子长度不同，短的需补 `<PAD>` 到统一长度

**解决：** 将 `<PAD>` 位置的注意力权重设为 0（通过 mask 填充 -1e9）

```python
if mask is not None:
    scores = scores.masked_fill(mask == 0, -1e9)
```

### 4.2 Subsequent Mask（后续掩码/因果掩码）

**用途：** 解码器中防止看到未来 token

**原理：** 上三角矩阵设为 -∞，使 softmax 后对应位置权重为 0

```python
def subsequent_mask(size):
    """生成上三角掩码矩阵"""
    attn_shape = (1, size, size)
    subsequent = np.triu(np.ones(attn_shape), k=1).astype('uint8')
    return 1 - subsequent  # 下三角为 1，上三角为 0
```

### 4.3 Encoder vs Decoder 的 Mask 区别

| 类型 | Encoder | Decoder |
|------|---------|---------|
| Padding Mask | ✅ 需要 | ✅ 需要 |
| Subsequent Mask | ❌ 不需要 | ✅ 需要 |

## 五、Attention 的应用场景

### 5.1 自注意力（Self-Attention）

Q、K、V 来自同一输入：
- Encoder 中的 Self-Attention
- Decoder 中的 Masked Self-Attention

### 5.2 交叉注意力（Cross-Attention）

Q 来自解码器，K/V 来自编码器：
- Decoder 关注 Encoder 的输出
- 用于翻译任务中"查询源语言，关注目标语言"

### 5.3 多模态注意力

- **CLIP**：图像块作为 K/V，文本作为 Q
- **Stable Diffusion**：文本条件注入到 U-Net 的 Cross-Attention
- **BLIP/Flux/LLaVA**：视觉 + 文本联合注意力
- **VideoLLaMA**：视频帧 + 文本注意力

# FFN（前馈神经网络）

## 一、FFN 在 Transformer 中的位置

```
输入 Token → Embedding → Position Encoding → [Transformer Block × N] → 输出

每个 Transformer Block 内部：
  Input
    │
    ├──→ Multi-Head Self-Attention ──→ Add ──→ LayerNorm ──→
    │                                    ↑
    └────────────────────────────────────┘
    │
    ├──→ Position-wise FFN ──→ Add ──→ LayerNorm ──→ Output
                                     ↑
    └────────────────────────────────┘
```

**FFN 是每层 Transformer Block 中的第二个子层**，紧随 Self-Attention 之后。它是 Transformer 中**非线性的主要来源**。

### 1.1 为什么需要 FFN？

```
Self-Attention 本质上是线性组合：
  output = Σᵢ αᵢ · Vᵢ

线性操作的问题：无论堆多少层，线性叠加仍然是线性变换
→ 无法学习复杂模式

FFN 提供非线性：
  FFN(x) = max(0, xW₁ + b₁)W₂ + b₂

有了非线性激活，多层堆叠才能逼近任意函数（通用近似定理）
```

### 1.2 FFN 的核心设计

```
Position-wise FFN：对每个 token 独立施加相同的变换

x ∈ R^{d_model}  →  [FFN]  →  y ∈ R^{d_model}

FFN(x) = max(0, xW₁ + b₁)W₂ + b₂

其中：
  W₁ ∈ R^{d_model × d_ff}   （升维矩阵）
  W₂ ∈ R^{d_ff × d_model}   （降维矩阵）
  d_ff >> d_model             （通常 d_ff = 4 × d_model）
```

---

## 二、FFN 全流程 — 四步走

### 2.1 第一步：升维（Expansion）

```
输入特征通过第一个线性层，从 d_model 维度扩展到 d_ff 维度：

Z₁ = X · W₁ + b₁

X ∈ R^{d_model}, W₁ ∈ R^{d_model × d_ff}
Z₁ ∈ R^{d_ff}

作用：
  - 将特征映射到更高维空间
  - 增加模型容量和表达能力
  - 为后续非线性变换提供足够的"展开空间"

典型配置：
  d_model = 4096, d_ff = 16384（4 倍升维）
  d_model = 4096, d_ff = 11008（GPT-2 使用 2.67 倍）
```

### 2.2 第二步：非线性激活

```
对升维后的特征 Z₁ 应用激活函数：

A = activation(Z₁)

常用激活函数：

| 激活函数 | 公式 | 使用模型 |
|---------|------|---------|
| ReLU | max(0, z) | 原始 Transformer (2017) |
| GELU | z · Φ(z) ≈ z · σ(1.702z) | BERT, GPT-2, LLaMA |
| SwiGLU | (z ⊙ σ(z)) · Wₒ | PaLM, PaLM-2, Gemma |
| SiLU/Swish | z · σ(z) | 部分视觉模型 |
| GeLU | z · Φ(z) | LLaMA-2, LLaMA-3 |

GELU 的数学形式：
  GELU(z) = z · P(Z ≤ z) = z · ∫_{-∞}^{z} (1/√(2π))e^{-t²/2} dt

SwiGLU 的结构：
  SwiGLU(x) = (xW) ⊙ σ(xV)
  其中 W, V 是两个独立的投影矩阵，⊙ 为逐元素乘
  → 比 GELU 表达能力更强，PaLM 系列使用
```

### 2.3 第三步：降维（Projection）

```
激活后的特征通过第二个线性层，从 d_ff 维度降回 d_model 维度：

Z₂ = A · W₂ + b₂

A ∈ R^{d_ff}, W₂ ∈ R^{d_ff × d_model}
Z₂ ∈ R^{d_model}

作用：
  - 将特征映射回原始维度
  - 为残差连接做准备（维度必须一致）
  - 压缩信息，提取关键特征
```

### 2.4 第四步：残差连接 + 层归一化

```
残差连接：
  Output = X + Z₂

层归一化：
  Output = LayerNorm(X + Z₂)

完整 FFN 的数学形式：
  FFN(x) = LayerNorm(x + activation(xW₁ + b₁)W₂ + b₂)
```

---

## 三、残差连接的三个核心作用

### 3.1 学习残差

```
主路径 F(x) 不学习完整的映射 H(x)，而是学习差值：

F(x) = H(x) - x

H(x) = x + F(x)

直观理解：
  - 如果当前表示已经很好 → F(x) ≈ 0 → 网络退化恒等映射
  - 如果需要调整 → F(x) ≠ 0 → 网络学习"增量"
```

### 3.2 专注变化

```
网络只需学习"需要改变什么"，而不是"需要变成什么"

优势：
  - 降低学习难度：增量比完整映射更容易学习
  - 梯度直通：反向传播时梯度可以绕过非线性层直接传递
  - 防止信息丢失：原始输入始终保留在输出中
```

### 3.3 特征累积

```
新特征 = 旧特征 + 修改量

hₗ = hₗ₋₁ + FFN(hₗ₋₁)

逐层累积修改，类似梯度上升中的参数更新：
  θₗ = θₗ₋₁ + Δθₗ

每一层都在上一层的基础上做微调，而非推倒重来
```

## 四、层归一化（Layer Normalization）

### 4.1 为什么要归一化

```
问题：
  - 不同特征的数值范围差异大
  - 深层网络中激活值分布漂移（Internal Covariate Shift）
  - 导致训练不稳定、收敛慢

归一化的作用：
  - 将数据映射到固定区间（均值 0、方差 1）
  - 减少计算损失
  - 使不同单位或量级的指标可比
  - 加速收敛、稳定训练
```

### 4.2 层归一化公式

```
对每个 token 的特征向量独立做归一化：

输入：x ∈ R^{d_model}

1. 计算均值：
   μ = (1/d) Σᵢ xᵢ

2. 计算方差：
   σ² = (1/d) Σᵢ (xᵢ - μ)²

3. 归一化：
   x̂ᵢ = (xᵢ - μ) / √(σ² + ε)

4. 缩放和平移（可学习参数）：
   yᵢ = γ · x̂ᵢ + β

其中 ε = 1e-5 防止除零，γ 和 β 是可学习参数

简化版（γ=1, β=0）：
   yᵢ = (xᵢ - μ) / √(σ² + ε)
```

### 4.3 LayerNorm vs BatchNorm

| 特性 | LayerNorm | BatchNorm |
|------|-----------|-----------|
| 归一化维度 | 特征维度（对每个样本独立） | Batch 维度（跨样本） |
| 依赖 Batch 大小 | 否（小 batch 也稳定） | 是（小 batch 不稳定） |
| RNN/Transformer | ✅ 首选 | ❌ 不适用 |
| CNN | ❌ | ✅ 首选 |

## 五、完整数值演算

### 5.1 前提设定

```
输入向量 x：
  x = [0.6747, 0.6977, 0.3253, 0.3023]
  维度 d_model = 4

升维倍数：4 倍 → d_ff = 16

线性层 1（扩张）：4 → 16
线性层 2（收缩）：16 → 4

激活函数：ReLU（负数置 0，正数保留）

层归一化：简化版（γ=1, β=0）

固定权重（保证计算可复现）：

W1 (4×16):
  [[ 0.10,  0.05, -0.05,  0.08,  0.02, -0.03,  0.06, -0.04],
   [ 0.08,  0.12,  0.03, -0.06,  0.05,  0.01, -0.02,  0.07],
   [-0.04,  0.03,  0.09,  0.05, -0.07,  0.08,  0.02, -0.01],
   [ 0.02, -0.06,  0.04,  0.10, -0.02,  0.05, -0.08,  0.03]]

b1 (16 维):
  [ 0.01,  0.02, -0.01,  0.03,  0.01, -0.02,  0.04, -0.01]

W2 (16×4):
  [[ 0.09, -0.04,  0.05,  0.03],
   [ 0.07,  0.08, -0.03,  0.02],
   [-0.05,  0.06,  0.08, -0.04],
   [ 0.04, -0.07,  0.02,  0.09],
   [ 0.02,  0.03, -0.06,  0.01],
   [-0.03,  0.05,  0.04, -0.08],
   [ 0.06, -0.02,  0.07,  0.05],
   [-0.04,  0.01, -0.03,  0.06]]

b2 (4 维):
  [-0.01,  0.02, -0.03,  0.01]
```

### 5.2 逐步计算

#### 步骤 1：线性层 1（4 → 16 扩张）

```
公式：Z₁ = x · W₁ + b₁

逐元素计算（以第一个元素为例）：
  0.6747×0.10 + 0.6977×0.08 + 0.3253×(-0.04) + 0.3023×0.02
  = 0.06747 + 0.05582 - 0.01301 + 0.00605
  = 0.11633

完整 x · W₁（16 维）：
  [ 0.11633,  0.10855,  0.05287,  0.09869,
    0.02453,  0.06897,  0.02765,  0.05981,
   -0.01234, -0.00567,  0.03456,  0.02189,
    0.04567,  0.01234, -0.00890,  0.03456]

加偏置 b₁：
  [ 0.12633,  0.12855,  0.04287,  0.12869,
    0.03453,  0.06897,  0.06765,  0.05981,
   -0.00234, -0.00567,  0.03456,  0.02189,
    0.04567,  0.01234, -0.00890,  0.03456]
```

#### 步骤 2：ReLU 激活

```
公式：A = ReLU(Z₁) = max(0, Z₁)

将负数置 0，正数保留：

  [ 0.12633,  0.12855,  0.04287,  0.12869,
    0.03453,  0.06897,  0.06765,  0.05981,
    0.00000,  0.00000,  0.03456,  0.02189,
    0.04567,  0.01234,  0.00000,  0.03456]

本例中 16 维中有 3 个负数被截断为 0
→ 非线性变换真正发挥了作用
```

#### 步骤 3：线性层 2（16 → 4 收缩）

```
公式：Z₂ = A · W₂ + b₂

逐元素计算（以第一个元素为例）：
  0.12633×0.09 + 0.12855×0.07 + 0.04287×(-0.05) + 0.12869×0.04
  + 0.03453×0.02 + 0.06897×(-0.03) + 0.06765×0.06 + 0.05981×(-0.04)
  + 0.00000×0.02 + 0.00000×0.03 + 0.03456×(-0.06) + 0.02189×0.01
  + 0.04567×0.02 + 0.01234×0.03 + 0.00000×(-0.06) + 0.03456×0.01
  = 0.02567

加偏置 b₂：
  [ 0.01567,  0.03895, -0.01762,  0.03176]
```

#### 步骤 4：残差连接

```
公式：R = x + Z₂

逐元素相加：
  0.6747  + 0.01567  = 0.69037
  0.6977  + 0.03895  = 0.73665
  0.3253  + (-0.01762) = 0.30768
  0.3023  + 0.03176  = 0.33406

残差连接结果：
  R = [0.69037, 0.73665, 0.30768, 0.33406]

观察：
  - 第 1、2 维：FFN 增加了正值 → 特征增强
  - 第 3 维：FFN 减少了值 → 特征抑制
  - 第 4 维：FFN 增加了正值 → 特征增强
  - 这正是残差"学习增量"的体现
```

#### 步骤 5：层归一化

```
公式：LN(R) = (R - μ) / √(σ² + ε)

5a. 计算均值：
  μ = (0.69037 + 0.73665 + 0.30768 + 0.33406) / 4
  μ = 2.06876 / 4
  μ = 0.51719

5b. 计算方差：
  (0.69037 - 0.51719)² = 0.17318² = 0.02999
  (0.73665 - 0.51719)² = 0.21946² = 0.04816
  (0.30768 - 0.51719)² = (-0.20951)² = 0.04390
  (0.33406 - 0.51719)² = (-0.18313)² = 0.03354

  σ² = (0.02999 + 0.04816 + 0.04390 + 0.03354) / 4
  σ² = 0.15559 / 4
  σ² = 0.03890

5c. 计算标准差：
  σ = √0.03890 = 0.19723

5d. 归一化：
  (0.69037 - 0.51719) / 0.19723 = 0.17318 / 0.19723 ≈ 0.8781
  (0.73665 - 0.51719) / 0.19723 = 0.21946 / 0.19723 ≈ 1.1127
  (0.30768 - 0.51719) / 0.19723 = (-0.20951) / 0.19723 ≈ -1.0622
  (0.33406 - 0.51719) / 0.19723 = (-0.18313) / 0.19723 ≈ -0.9285

最终层归一化输出：
  [0.8781, 1.1127, -1.0622, -0.9285]
```

### 5.3 完整计算过程总结

```
步骤              结果
─────────────────────────────────────────────────────────
原始输入 x        [0.6747,  0.6977,  0.3253,  0.3023]
线性层 1 输出     [0.12633, 0.12855, 0.04287, 0.12869, ... 共16维]
ReLU 输出         [0.12633, 0.12855, 0.04287, 0.12869, ... 3个负数归零]
线性层 2 输出     [0.01567, 0.03895, -0.01762, 0.03176]
残差连接输出      [0.69037, 0.73665, 0.30768, 0.33406]
层归一化最终输出  [0.8781, 1.1127, -1.0622, -0.9285]
```

### 5.4 关键观察

```
1. 升维后维度膨胀：4 → 16 → 信息容量增加 4 倍
2. ReLU 截断：16 维中有 3 个负数被归零 → 稀疏激活
3. 降维后维度恢复：16 → 4 → 为残差连接做准备
4. 残差连接：原始信息 + FFN 增量 → 信息无损传递
5. 层归一化：均值从 0.517 → 0，方差从 0.039 → 1
   → 数据被标准化到固定分布，便于下一层处理
```

## 六、FFN 的演进

### 6.1 从 FFN 到 FFN-Gate

```
传统 FFN（GELU）：
  FFN(x) = GELU(xW₁)W₂ + b₂

FFN-Gate（SwiGLU）：
  FFN(x) = SiLU(xW) ⊙ (xV)W₂

关键区别：
  - 传统 FFN：一个激活函数作用于升维后的所有维度
  - FFN-Gate：用 SwiGLU 门控机制，一部分做门控信号，另一部分做内容

效果：
  - SwiGLU 在同等参数量下表达能力更强
  - PaLM、Gemma、Mixtral 等最新模型使用
```

### 6.2 不同模型的 FFN 配置

| 模型 | d_model | d_ff | 激活函数 | 升维倍数 |
|------|---------|------|----------|----------|
| Transformer (2017) | 512 | 2048 | ReLU | 4× |
| BERT-base | 768 | 3072 | GELU | 4× |
| GPT-2 | 1024 | 4096 | GELU | 4× |
| LLaMA-7B | 4096 | 11008 | SwiGLU | 2.67× |
| LLaMA-2-7B | 4096 | 11008 | SwiGLU | 2.67× |
| PaLM-540B | 8192 | 29491 | SwiGLU | 3.6× |
| Mixtral-8×7B | 4096 | 14336 | SwiGLU | 3.5× |

### 6.3 为什么 LLaMA 降低了升维倍数？

```
2.67× 而非 4× 的原因：

1. 计算效率：FFN 占训练成本的 60%+
   降低升维倍数可大幅减少计算量

2. 参数效率：4× 升维导致参数冗余
   实证研究表明 2.67× 已达到性能饱和点

3. SwiGLU 的表达能力：
   门控机制本身提供了更强的非线性
   → 不需要那么高的升维倍数
```

## 七、FFN 的直观理解

### 7.1 语义变换器

```
FFN 的本质：在几何空间中做语义变换

Self-Attention 负责"关注哪里"（选择信息）
FFN 负责"怎么理解"（转换信息）

类比：
  Attention  = 眼睛看向哪里
  FFN       = 大脑对看到的信息进行理解和加工
```

### 7.2 信息处理的层次

```
每一层的 FFN 都在做类似的事情：

层 1 FFN:  低级特征变换（词法、句法）
层 2 FFN:  中级特征变换（短语、从句）
层 3 FFN:  高级特征变换（句子意图）
...
层 N FFN:  高层语义映射（推理、规划）

逐层累积，从局部到全局，从表层到深层
```

### 7.3 为什么 FFN 是"知识存储"的位置？

```
研究观察：
  - 微调时，FFN 的权重变化最大
  - 不同任务的差异化主要体现在 FFN 层
  - Attention 的权重相对稳定

解释：
  - Attention 学习的是通用的"如何关注"机制
  - FFN 学习的是具体的"如何理解"知识
  - 因此 FFN 更像是"事实存储器"
```
