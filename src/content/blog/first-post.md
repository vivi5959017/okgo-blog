# Hello World! 👋
大模型根据不同任务目的，训练数据和训练方式会不同，常见的有 Bert、GPT、clip、视频生成、3D 生成、世界模型等任务类型。
 假设你要训练一个做文本分类的 BERT 模型，数据集是中文情感分析，二分类任务。 第一步，准备数据 你有一堆句子和对应的标签，正面是 1 负面是 0。分词之后转成 token ID，加上特殊标记 [CLS] 和 [SEP]，padding 到统一长度，打包成 batch。 第二步，前向传播 一个 batch 的数据喂进模型。词嵌入层把 token ID 转成向量，加上位置编码。然后进入 12 层 Transformer encoder，每一层做自注意力和 FFN，中间有残差连接和 LayerNorm。最后取 [CLS] 位置的输出向量，过一个分类头得到二分类的 logits。这一步就是所有教程在讲的东西前向传播。 第三步，算损失 logits 和真实标签算交叉熵损失，得到一个标量 loss。 第四步，反向传播 调用 loss.backward()，PyTorch 自动帮你算所有参数的梯度。这一步在代码里就一行，背后的计算图遍历、链式法则应用、梯度累加，全是框架帮你做的。 第五步，更新参数 调用 optimizer.step()，根据梯度更新所有参数。用的优化器一般是 AdamW，学习率调度用 warmup 加线性衰减。 第六步，清空梯度，进入下一个 batch 调用 optimizer.zero_grad()，然后重复第二步到第五步。
假如你要训练一个 GPT 生成式模型任务，一般生成式语言模型遵循预训练、指令微调、人类对齐三个过程。 第一步，预训练，基础能力的建立 先让模型对于语言符号有个基本了解 数据配比：训练数据主要来自网页、图书、代码占据比例最高，通过数据工程进行数据清洗与合成。绝大部分主流模型用了 10T 以上词元训练量。以下为 LIama3 的数据配比参考：通用 50%、数学/推理 25%、代码 17%、多语言 8%。也可采用自动化配比工具 DoRemi。 训练过程： 第一阶段中英双语适配，第二阶段合成数据增强。数据集可拆分多阶段，先小部分数据，进行效果评估，然后再大批量数据训练。第二步，指令微调，有监督学习 使用问答格式的数据对模型进行有监督微调，指令数据集的标准人工成本大，可通过大模型上下文学习自动化构建。 数据配比： 不同指令格式数据集的配比，专用大模型一般数千条，通用大模型则需要数十万条或更多可取得不错效果。数据种类覆盖：数学、代码、多语言、推理、智能体等。数据类型：复杂指令、日常任务、合成实例，指令、对话、COT 微调。 第三步，人类对齐，强化学习 通过强化学习为大模型引入人类价值观。一般有这三种方式：①基于人类偏好的 Instruct 数据，人工标注在预训练阶段对齐。②人工结果反馈的奖励模型训练。（打分、排比、对比）③强化学习算法的奖励模型。而在模式上又分为结果监督和过程监督两种。 主流采用 GRPO 算法，采用的是组内每条数据的奖励值，归一化后进行优势估计，原 KL 惩罚项改为其无偏估计，该函数恒为正值使训练更加稳定。
训练过程参数的选择，首先是样本量的多少，在预训练阶段需要，前面根据论文各模型数据配比可以参考。在后训练阶段，总体原则遵循高质量数据集＞数据多样性＞数据量，数据量一般根据模型参数量和任务类型，数据量在数千条。逻辑：基座模型已经拥有全部常识、语言、语义知识，只需要学习新的 “行为模式”：指令跟随、因果结构、思考路径，更多的是行为学习而不是基础知识学习，如果数据量过多，可能会出现灾难性遗忘。 Batch size 是单次送入模型、参与一次完整前向 + 反向传播的样本数量，即数据切片策略。①一次性将 N 个样本送入模型推理，得到 N 个独立样本损失；对 N 个损失做均值 / 求和，得到该批次整体损失。②链式求导从批次总损失反向逐层计算每个权重的梯度，最终得到 N 个样本梯度的平均值。③优化器（Adam/SGD 等）拿到反向传播输出的批次梯度，乘以学习率，更新网络权重。基于以上过程，把梯度下降想象成下山： Full Batch = 站在山顶俯瞰全貌，看清最佳下坡方向（精准但看不到细节地形） Mini-batch = 每走几步观察一小片区域，边走边调整（兼顾效率与适应性） 所以到这里就比较清晰理解： 大批次 → 梯度接近全局最优方向，收敛稳定，容易陷入尖锐极小值 小批次 → 梯度带噪声，可能跳出局部最优，更容易找到平坦极小值（泛化更好） 另外更新权重还是学习率有关，按照经验在大批次时，还要结合学习率参数和 warmup 策略。 总结起来，按数据集规模初选档位（小数据集小 batch，大数据集可大 batch），选择合适的 batch size 需要综合考虑硬件资源、训练效率、模型泛化、学习率策略等多个维度。 学习率，做训练时的更新幅度，所以结合训练目的来选择学习率参数。在基座模型参数已经是最优稳定点，SFT 只需要做小调整。在预训练时，随机初始化到最优解，需要大学习率。在强化学习时，更小的 lr 学习率，做精调。 Epoch（轮次）学习的次数。最后模型训练根据实验结果来调整任务，是一套完整的训练、评估、优化流程。
