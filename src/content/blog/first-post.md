# Hello World! 👋

这是我使用 **Astro** 搭建的第一篇博客文章！

## 为什么选择 Astro？

我选择 Astro 是因为：

1. **超快速** - 默认零 JavaScript，加载速度飞快
2. **SEO友好** - 静态页面，搜索引擎更容易收录
3. **体验好** - Markdown 写文章，体验极佳
4. **功能强** - 支持各种框架组件集成

## 技术栈

这个博客的技术栈：

- **Astro** - 静态站点生成器
- **TypeScript** - 类型安全
- **Vercel** - 部署平台
- **Markdown** - 文章编写
